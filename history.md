### Known limitations

- README markets loco-mujoco as an "imitation learning benchmark for whole-body locomotion control", but the env interface is RL (`env.step` returns shaped reward; `RLFactory` is the default factory). The classifier resolves the framing/interface mismatch by trusting the interface (8/8 aux score). Imitation is available as `ImitationFactory` and through the `gail`/`amp`/`rl_mimic` dispatcher algos — both still go through the same RL-style step contract.
- No WebSocket policy-server protocol — `scripts/run_demo.py` and `scripts/run_eval.py` do **not** take `--policy_server_addr`. This is the case-study "no policy-server" RL benchmark.
- The mocap datasets (AMASS / LAFAN1) are gated behind external license terms and must be configured per-host with `loco-mujoco-set-amass-path` / `loco-mujoco-set-lafan1-path` before `ImitationFactory` can use them.
- `MyoSkeleton` requires manual license acceptance — set `LOCO_AUTO_MYO=1` on the compose env to auto-accept on container start, or run `loco-mujoco-myomodel-init` interactively.
- The dispatcher's `ALGO_MAP` (`scripts/train_rl_policy.py`) is pinned to the upstream `examples/training_examples/jax_*/experiment.py` paths. If upstream renames a training example, edit `ALGO_MAP` directly.
- L3_RL writes to `/workspace/outputs/<date>/<time>/` rather than `/tmp/` (Hydra default); not a `/tmp` violation per the smoke-test contract because the path is benchmark-managed and mount-visible from the host.
- benchmark-spec.json is intentionally NOT generated (RL benchmarks; spec capture is IL-only per skill contract).
- PyTorch is intentionally absent from the image; do not treat `import torch` failures as regressions — they are by design.
