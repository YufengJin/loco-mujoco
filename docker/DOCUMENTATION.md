## Lessons captured in the Dockerfile / compose

1. **`MUJOCO_GL=egl` required for headless replay rendering** — without it, `mjx_render` raises `mujoco.FatalError: gladLoadGL error` at the end of training when `experiment.py` replays the learned policy. `libegl1` was already in the apt layer; only the env var was missing.
2. **`wandb` is an implicit training dep** — `examples/training_examples/*/experiment.py` does `import wandb` at module load even when `wandb=disabled`. Not in `pyproject.toml` core deps. Added as a benchmark-layer pip install.
3. **`experiment.validation.num` must divide `num_updates`** — smoke runs with very small `total_timesteps` trigger `ZeroDivisionError` at `num_updates // validation_interval`. The L3_RL smoke command overrides `experiment.validation.num=1`.
4. **Dispatcher ALGO_MAP** uses `rl_mimic → jax_rl_mimic/experiment.py` (the DeepMimic-style training loop reuses `PPOJax` — there is no `DeepMimicJax` class).
