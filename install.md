# loco-mujoco — Install Recipe

Minimum commands to reproduce this benchmark container from a fresh clone. Generated by `benchmark-env-generator` skill (sub-skill of `env-generator`).

## Host prerequisites

- Docker (>= 24) and the Compose v2 plugin
- NVIDIA driver + NVIDIA Container Toolkit with a GPU visible to `nvidia-smi`
- Disk budget for first-run HuggingFace dataset download (only triggered on `ImitationFactory.make(...)`; skip if you only run RL with `RLFactory`)

## Build the image

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cuda:12.4.1-cudnn-runtime-ubuntu22.04`
Python: `3.10` (managed by `uv`)

JAX with CUDA 12 wheels and `imageio[ffmpeg]` are layered on top of the locked `uv.lock`; `wandb` is pre-installed for the in-tree training examples.

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it loco-mujoco_container bash
```

For an X11 / GUI session (swap the compose profile — container name is shared, only one may run):

```bash
docker compose -f docker/docker-compose.headless.yaml down
xhost +local:docker
docker compose -f docker/docker-compose.x11.yaml up -d
```

The X11 compose profile flips `MUJOCO_GL=glfw` (windowed rendering) and `WANDB_MODE=online`.

## First-run sanity checks (inside the container)

```bash
nvidia-smi
python -c "import jax; print(jax.devices(), jax.default_backend())"
python -c "import loco_mujoco; print(loco_mujoco.__file__)"
```

The last line must resolve under `/workspace/loco_mujoco/` — that proves the mounted source is what the interpreter imports (editable install succeeded).

### Optional asset / dataset download

The entrypoint prompts rather than force-downloads. To auto-accept on subsequent container starts:

- `LOCO_AUTO_MYO=1` — accepts the MyoSkeleton license and pulls the model
- Run one of `loco-mujoco-download` / `loco-mujoco-download-real` / `loco-mujoco-download-perfect` once to seed `~/.cache/huggingface/datasets/`
- Or let `ImitationFactory.make(...)` lazy-download on first use

The HuggingFace cache is bind-mounted to `<repo>/.hf_cache/` so restarts do not re-download.

## Category-specific smoke run

### RL: short training run via the dispatcher

```bash
docker exec loco-mujoco_container bash -c \
    "WANDB_MODE=disabled python scripts/train_rl_policy.py --algo ppo \
        experiment.total_timesteps=5000 \
        experiment.num_envs=8 experiment.num_steps=16 experiment.debug=true \
        wandb.project=smoke"
```

Available algorithms: `ppo, gail, amp, rl_mimic` (baselines mode: `dispatcher` — delegates to `examples/training_examples/jax_*/experiment.py`).

The trained checkpoint is saved under `outputs/<date>/<time>/<AlgoClass>_saved.pkl`. To replay it:

```bash
docker exec loco-mujoco_container python scripts/run_eval.py \
    --checkpoint_path outputs/<date>/<time>/PPOJax_saved.pkl --algo ppo \
    --n-envs 1 --n-steps 1000 --deterministic
```

For a quick random-action sanity rollout (no checkpoint required):

```bash
docker exec loco-mujoco_container python scripts/run_demo.py \
    --env_name UnitreeH1 --n-steps 50
```

## Stop / clean up

```bash
docker compose -f docker/docker-compose.headless.yaml down
```
